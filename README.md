# 🌿 KR_EEIO (GHG Only)
**Bank of Korea Environmentally Extended Input-Output Analysis — Greenhouse Gas Scope Analysis Model**

---

## I. Overview

**EEIO (Environmentally Extended Input-Output)** is an analytical framework that combines greenhouse gas and energy-related statistics with the Input-Output Table (one of the National Accounts statistics) to precisely decompose and allocate the greenhouse gas emissions of individual industries within the macroeconomy into **Scope 1 · 2 · 3**.

- The total inventory amount is fixed as the base emissions (Scope 1), and **indirect emissions from electricity use (Scope 2)** and **indirect emissions from raw material use, etc. (Scope 3)** are mathematically derived through production-inducement coefficients.
- A **constant-price Input-Output Table** is compiled to remove price effects, enabling **time-series comparison** of each industry's emission coefficients, etc.
- For SMEs and others for whom detailed analysis is difficult, a **Simulator** was also developed to allow simplified carbon emission calculations using only limited data such as the company's industry, sales revenue, and major raw materials.

## III. Compilation Method

### 1. Industry-level GHG Emissions

Based on the GHG inventory, but where inventory items correspond to multiple industries or are unclear, allocation data from the Energy Balance and the Input-Output Table are used.

> 📄 For details, see **National Accounts Review (January 2025), "Trial Results of the Air Emissions Account"**

### 2. Constant-Price Input-Output Table

- Compiled by applying price indices to the current-price Input-Output Table, using the **Double-Deflation** method
- Domestic and imported goods are distinguished, using the following indices:
  `PPI` · `CPI` · `GDP Deflator` · `Export/Import Price Index` · `Exchange Rate` · `Services Price Index (IMF)`

## IV. EEIO Model Overview

### Key Concepts

| Concept | Description |
|------|------|
| **Input-Output Table (IO Table)** | A national statistic expressing inter-industry transactions of goods and services as a matrix |
| **Leontief Inverse Matrix L** | The total production induced across all industries per one-unit increase in final demand |
| **Direct Emission Coefficient B** | GHG directly generated by industry *i* per KRW 1 million of output (kt CO₂eq) |
| **Supply Chain Induced Coefficient B×L** | Total GHG induced across the entire supply chain per KRW 1 million of final demand |

### Key Formulas

$$A = Z \div X \quad \text{(Input Coefficient Matrix)}$$

$$L = (I - A)^{-1} \quad \text{(Leontief Inverse Matrix)}$$

$$B = E \div X \quad \text{(Direct Environmental Coefficient)}$$

$$\text{Total Induced Coefficient} = B \cdot L$$

> $Z$: Intermediate goods transaction matrix (33×33) &nbsp;|&nbsp; $X$: Total output vector (33×1) &nbsp;|&nbsp; $E$: Direct GHG vector

### ⚠️ Correction for Double-Counting of Scope 2 in the Power Sector

| Item | Description |
|------|------|
| **Problem** | Due to the nature of self-consumed power in the electricity industry, Scope 1 is duplicated within M[D,D] |
| **Solution** | For the electricity industry only, correct via `Scope2[D] = M[D,D] − B[D]` |

## VI. Components

Compiled in both current prices and constant prices, with the following components:

| Item | Variable Name | Description |
|------|--------|------|
| Total Transaction Table | `T_mat_GHG` | Input-Output Table (imports + domestic) and industry-level emissions |
| Input (Emission) Coefficient | `Ad` | Emissions per unit of output (KRW million) |
| Production Inducement Coefficient | `Lf` | Total output across all industries induced by final demand (KRW million) for a specific item |
| Emission Inducement Coefficient | `M` | Total emissions across all industries induced by final demand (KRW million) for a specific item |
| Emissions by Final Demand Item | `M·fd` | Total emissions induced by each final demand item |
| Output-based Emissions | `M·X(diag)` | Total emissions across all industries induced by the output of a specific item |
| Emission Scopes | `Scopes 1, 2, 3` | Classification of direct and indirect emissions |
| Import Transaction Table | `I_mat` | Input-Output Table (imports) |
| Domestic Transaction Table | `D_mat` | Input-Output Table (domestic) |
